# LAVT: Language-Aware Vision Transformer for Referring Image Segmentation

**Paper:** LAVT: Language-Aware Vision Transformer for Referring Image Segmentation
**Authors:** Zhao Yang, Jiaqi Wang, Yansong Tang, Kai Chen, Hengshuang Zhao, Philip H.S. Torr
**Venue:** CVPR 2022
**Analysis Depth:** Standard

## Quick Summary / 快速概要

**EN:** LAVT performs early fusion of linguistic and visual features within the encoder stages of a Swin Transformer, replacing the conventional cross-modal decoder paradigm. Through a pixel-word attention module (PWAM) and a language gate (LG) at each stage, LAVT achieves 72.73% oIoU on RefCOCO, surpassing VLT by +7.08% with only a lightweight mask predictor.

**ZH:** LAVT 在 Swin Transformer 编码器各阶段内部执行语言与视觉特征的早期融合，取代传统的跨模态解码器范式。通过在每个阶段配置像素-词注意力模块 (PWAM) 和语言门控 (LG)，LAVT 在 RefCOCO 上达到 72.73% oIoU，仅用轻量掩码预测器即超越 VLT +7.08%。

## Key Contributions / 核心贡献

1. **Encoder-Side Fusion** -- Integrates language into visual features during encoding, eliminating the need for complex cross-modal decoders
2. **Pixel-Word Attention Module (PWAM)** -- Dense pixel-word alignment at each Transformer stage via scaled dot-product attention
3. **Language Gate (LG)** -- Learnable gating mechanism controlling multi-modal information flow as residual additions

## Relevance to TextMamba3D / 与 TextMamba3D 的关联

LAVT's paradigm of injecting text features directly into the vision encoder at multiple scales is highly relevant to text-guided 3D segmentation. The PWAM design pattern could be adapted for Mamba-based encoders where language features are injected at each resolution stage during volumetric encoding.
