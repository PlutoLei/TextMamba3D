## Quick Summary / 快速概要

**EN:** RLEG improves contrastive vision-language representation learning by using pretrained diffusion models to generate cross-modal embedding-level augmentations online during training. With ViT-B/32 on YFCC-15M, it achieves 39.1% ImageNet zero-shot top-1 accuracy (+9.0 pp over CLIP baseline) and consistent improvements on retrieval, detection, segmentation, and image generation tasks. Generators are used only during training, adding zero inference cost.

## Key Contributions / 核心贡献

1. **Diffusion-based Embedding Generation** -- Repurposes pretrained DALL-E 2 prior models as cross-modal embedding generators to produce augmented training samples directly in feature space
2. **Bidirectional Cross-modal Augmentation** -- Deploys both image-to-text and text-to-image generators to enrich both modalities symmetrically during contrastive learning
3. **Multiple Sampling Strategy** -- Generates K=4 embeddings per input with DDIM (5-10 steps), stabilizing training and accelerating convergence with no inference-time overhead

## Relevance to TextMamba3D / 与 TextMamba3D 的关联

RLEG demonstrates that diffusion models can serve as embedding-level data augmenters for contrastive vision-language learning, which is directly relevant to TextMamba3D's text-guided 3D segmentation paradigm. The core insight -- densifying sparse embedding distributions by sampling from a learned generative manifold -- addresses the acute data scarcity problem in 3D medical imaging. The bidirectional cross-modal generation strategy could inform how text prompts and volumetric features are aligned in the TextMamba3D framework.
