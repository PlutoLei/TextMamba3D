## Quick Summary / 快速概要

**English:**
DenseCLIP converts CLIP's image-level image-text matching into pixel-level dense prediction by computing pixel-text score maps — per-pixel cosine similarity between visual features and category text embeddings. Context-aware prompting (post-model variant) refines text embeddings using visual context via a Transformer decoder, producing image-adaptive text representations. The framework is backbone-agnostic and achieves +2.4 mIoU on ADE20K (ResNet-50, 43.5 vs. 41.1 baseline) with negligible additional parameters. Gains are consistent across ResNet, Swin Transformer, and ViT backbones, and transfer to object detection on COCO (40.2 AP_box with Mask R-CNN).

**中文：**
DenseCLIP 通过计算像素-文本得分图（视觉特征与类别文本嵌入的逐像素余弦相似度），将 CLIP 的图像级匹配转换为像素级密集预测。上下文感知提示（后置模型变体）通过 Transformer 解码器利用视觉上下文精炼文本嵌入，生成图像自适应的文本表示。该框架与骨干网络无关，在 ADE20K 上（ResNet-50）实现 +2.4 mIoU（43.5 vs. 41.1 基线），额外参数极少。增益在 ResNet、Swin Transformer 和 ViT 上一致，并迁移至 COCO 目标检测（Mask R-CNN 40.2 AP_box）。

## Relevance to TextMamba3D / 与 TextMamba3D 的关联

DenseCLIP demonstrates that vision-language pretrained features can enhance dense prediction without modifying the visual backbone — a design principle directly applicable to 3D medical segmentation where backbone retraining is costly. The pixel-text score map mechanism provides a reference for integrating text descriptions of anatomical structures into volumetric segmentation. The context-aware prompting design (especially post-model variant) offers a lightweight approach to adapt text embeddings to 3D visual context.

DenseCLIP 证明视觉-语言预训练特征可在不修改视觉骨干的前提下增强密集预测——这一设计原则直接适用于骨干重训练成本高昂的 3D 医学分割。像素-文本得分图机制为将解剖结构文本描述整合到体积分割中提供了参考。上下文感知提示设计（尤其是后置模型变体）提供了一种轻量级方案，将文本嵌入适配至 3D 视觉上下文。
