# CRIS: CLIP-Driven Referring Image Segmentation

**Paper:** CRIS: CLIP-Driven Referring Image Segmentation
**Authors:** Zhaoqing Wang, Yu Lu, Qiang Li, Xunqiang Tao, Yandong Guo, Mingming Gong, Tongliang Liu
**Venue:** CVPR 2022
**Analysis Depth:** Standard

---

## Quick Summary / 快速概要

**EN:** CRIS transfers CLIP's multi-modal knowledge from image-level to pixel-level for referring image segmentation through a vision-language decoder and text-to-pixel contrastive learning. It achieves state-of-the-art results on RefCOCO (+4.89 IoU), RefCOCO+ (+8.88 IoU), and G-Ref (+5.47 IoU) without post-processing.

**ZH:** CRIS 通过视觉-语言解码器和文本-像素对比学习，将 CLIP 的多模态知识从图像级迁移到像素级，用于指代图像分割。在 RefCOCO（+4.89 IoU）、RefCOCO+（+8.88 IoU）和 G-Ref（+5.47 IoU）上取得最优结果，无需后处理。

## Key Contributions / 核心贡献

1. **Vision-Language Decoder** -- Propagates fine-grained textual semantics to pixel-level visual features via cross-attention
2. **Text-to-Pixel Contrastive Loss** -- Explicitly aligns text and pixel representations in a shared embedding space
3. **CLIP Knowledge Transfer** -- End-to-end framework for transferring image-level multi-modal knowledge to pixel-level tasks

## Relevance to TextMamba3D / 与 TextMamba3D 的关联

CRIS demonstrates effective cross-modal alignment at the pixel level using CLIP, which is directly relevant to text-guided 3D segmentation approaches. The decoder + contrastive loss paradigm may inform fusion strategies for text-driven volumetric segmentation.
