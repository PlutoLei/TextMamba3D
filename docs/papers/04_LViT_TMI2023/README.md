## Quick Summary / 快速概要

**English:**
LViT introduces text annotations as auxiliary supervision for semi-supervised medical image segmentation. The Double-U architecture combines a U-CNN and U-ViT branch via Pixel-Level Attention Module (PLAM), while Language-Vision (LV) loss aligns BERT-encoded text with pixel-level visual features. Exponential Pseudo-label Iteration (EPI) enables progressive semi-supervised training. On QaTa-COV19, LViT achieves 83.66% Dice (fully supervised) and 80.90% Dice with only 20% labeled data — 96.7% of full supervision performance.

**中文：**
LViT 将文本标注引入半监督医学图像分割作为辅助监督信号。Double-U 双分支架构通过像素级注意力模块（PLAM）融合 U-CNN 和 U-ViT 分支，语言-视觉损失（LV Loss）将 BERT 编码的文本与像素级视觉特征对齐，指数伪标签迭代（EPI）实现渐进式半监督训练。在 QaTa-COV19 上，LViT 全监督达到 83.66% Dice，仅 20% 标注即达 80.90% Dice——全监督性能的 96.7%。

## Relevance to TextMamba3D / 与 TextMamba3D 的关联

LViT demonstrates that text annotations can effectively complement pixel-level labels in medical image segmentation. The PLAM cross-attention fusion mechanism and LV loss design provide reference points for integrating language modalities into 3D medical segmentation architectures. The semi-supervised training strategy (EPI) is applicable to scenarios with limited 3D volumetric annotations.

LViT 证明文本标注可有效补充医学图像分割中的像素级标签。PLAM 交叉注意力融合机制和 LV Loss 设计为将语言模态整合到 3D 医学分割架构中提供了参考。半监督训练策略（EPI）适用于 3D 体积标注稀缺的场景。
