
### 4.4 常用参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--config` | 配置文件 | `configs/textbrats.yaml` |
| `--max-samples` | 限制样本数 | `--max-samples 100` |
| `--resume` | 恢复训练 | `--resume checkpoints/last.pth` |
| `--no-amp` | 禁用混合精度 | `--no-amp` |
| `--grad-accum` | 梯度累积步数 | `--grad-accum 8` |

## 五、配置文件说明

文件：`configs/textbrats.yaml`

```yaml
data:
  data_dir: "./data/BraTS2020/BraTS2020_TrainingData/MICCAI_BraTS2020_TrainingData"
  dataset_type: "textbrats"
  patch_size: [64, 64, 64]  # 8GB 内存用 64，16GB 可用 96
  batch_size: 1
  num_workers: 0  # WSL 中建议设为 0

model:
  img_size: [64, 64, 64]  # 与 patch_size 一致
  text_max_len: 256

training:
  epochs: 100
  lr: 0.0001
  patience: 20  # Early stopping
```

### 内存配置建议

| 物理内存 | patch_size | WSL memory |
|----------|------------|------------|
| 8GB | 64³ | 6GB |
| 16GB | 96³ | 12GB |
| 32GB | 128³ | 24GB |

## 六、常见问题

### 6.1 Bus error (core dumped)

**原因**: 内存不足或多进程问题

**解决**:
1. 设置 `num_workers: 0`
2. 减小 `patch_size` 为 64
3. 使用 `--max-samples` 限制样本

### 6.2 Mamba CUDA not available

**原因**: Windows 不支持 Mamba CUDA 内核

**解决**: 必须在 WSL2 Ubuntu 中运行

### 6.3 ImportError: GreedySearchDecoderOnlyOutput

**原因**: transformers 版本太新

**解决**:
```bash
pip install transformers==4.38.0
```

### 6.4 训练卡住不动

**原因**: 首次加载 Mamba CUDA 内核较慢

**解决**: 等待 1-2 分钟，会自动继续

## 九、项目创新点

1. **Mamba + 文本引导**: 首次将 Mamba 架构应用于文本引导 3D 医学分割
2. **无信息泄露**: 使用 TextBraTS 专家标注，避免从 GT 生成文本的问题
3. **高效融合**: 利用 Mamba 因果性实现文本-图像自然融合
4. **无文本推理**: 支持推理时不依赖文本输入
